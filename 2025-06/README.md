# Plots from June 2025 to April 2026

This directory contains plot assets and scripts from June 2025 to April 2026 for two papers, "Detecting In-Path Network Compression
in Uncooperative Environments" and "Fingerprinting and Biasing Bandwidth Measurements". The plots are organized based on paper-specific groups:

- `detect-in-path-compression`
- `bandwidth-measurements`

Each subfolder under those project folders corresponds to one plot used in a research paper.

**The data used to generate the figures is hardcoded directly in the notebooks**, so there is no separate input data files.

## How to Use the Notebooks

The notebooks in this directory were prepared to run in Google Colab rather than a local Jupyter environment. To regenerate a figure:

1. Open the corresponding `.ipynb` file in Google Colab.
2. Run the notebook cells from top to bottom.
3. Run the download cells to export the generated figure.

Colab already provides a Python runtime and usually includes the common plotting libraries needed for these notebooks. If a notebook reports a missing package, install it in a Colab cell with:

```python
!pip install matplotlib pandas seaborn
```

## File Type Explanation

- `.ipynb` files are **notebooks**: they contains the input data and generate the plots.
- `.pdf`, `.eps` files are **result files**: generated by the notebooks and **cropped** using pdfcrop.
- `.drawio.pdf` files are **editable source file** of draw.io diagram platfrom: they contains metadata and enables users to drag and drop the PDF back into the draw.io editor to edit the diagram if needed.

You can regenerate the result files by opening the corresponding notebook in Google Colab and rerunning it.
